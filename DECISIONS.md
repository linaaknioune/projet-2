# Journal des décisions techniques

## 1. Problème à résoudre
Prédire le prix d'une maison à partir de ses caractéristiques.

Le problème est une régression, car la variable cible est un prix numérique.

## 2. Langage de programmation
Décision : utiliser Python.

Justification : Python dispose de bibliothèques adaptées à l'analyse de données et au machine learning.

## 3. Préparation des données
Décision : examiner les valeurs manquantes, les types de variables et les données incohérentes avant l'entraînement.

Justification : la qualité des données influence les performances du modèle.

## 4. Bibliothèques
- pandas : manipulation des données.
- NumPy : calculs numériques.
- Matplotlib : visualisation.
- scikit-learn : entraînement et évaluation.
- pytest : tests automatisés.
- coverage : mesure de la couverture des tests.

## 5. Évaluation du modèle
Décision : séparer les données en ensembles d'entraînement et de test.

Les métriques seront choisies en fonction du notebook et du problème étudié.

## 6. Collaboration
Décision : utiliser un dépôt GitHub public.

Justification : centraliser le code, documenter le travail et faciliter la collaboration entre les membres.

## 7. Décisions à confirmer
- Jeu de données utilisé.
- Variables retenues.
- Modèle de régression choisi.
- Métriques d'évaluation finales.
